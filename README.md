# ZombieFPS
My fps game with zombies!!!
Don't copy my game (beacuse code is bad).

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "ZombieFPS.rbxlx"
```

Next, open `ZombieFPS.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

For more help, check out [the Rojo documentation](https://rojo.space/docs).
